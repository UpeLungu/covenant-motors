# Covenant Motors

Mobile-first dealership management web application built with Next.js, TypeScript and Supabase-ready architecture.

## Current build
- Responsive dashboard and sidebar
- Vehicle stock register and automatic stock IDs
- Drivers and collection trips
- Driver advances, expenses and reconciliation
- Customers, sales and payments
- Vehicle ledger, costing, documents and timeline
- Finance and accounting
- Tax Centre
- Reports and CSV/print exports
- Net profit/loss cost analysis
- Professional UI consolidation in progress
- Supabase-ready architecture

## Run locally
```bash
npm install
npm run dev
```

## Deployment
Import this repository into Vercel. Framework preset: Next.js. No environment variables are required for the current demo build.
