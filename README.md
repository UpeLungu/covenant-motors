# Covenant Motors

Mobile-first dealership management web application built with Next.js, TypeScript and Supabase-ready architecture.

## First build
- Responsive dashboard and sidebar
- Vehicle stock register
- Automatic stock IDs in the format `CM-YYYY-0001`
- Vehicle registration with duplicate VIN protection
- Search and status filters
- Vehicle detail and costing view
- Local demo storage for immediate testing
- Supabase schema foundation

## Run locally
```bash
npm install
npm run dev
```

## Deployment
Import this repository into Vercel. Framework preset: Next.js. No environment variables are required for the first demo build.
